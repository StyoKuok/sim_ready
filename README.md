# ObjectTwin project website

Public project page: https://styokuok.github.io/sim_ready/

Paper: https://arxiv.org/abs/2610.35904

This repository contains only the static website and its GitHub Pages workflow.
It contains no research repository history, manuscript sources, experiment runs,
or private configuration. The site is served from `site/` on the `main` branch.

To update the website, replace the static files in `site/` and push to `main`.
GitHub Actions publishes the updated page automatically.
